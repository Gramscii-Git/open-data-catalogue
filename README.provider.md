# $provider Open Data catalogue

This independently validated provider snapshot belongs to the European Open Data
Catalogue. It does not replace the combined catalogue.

| Field | Value |
| --- | --- |
| Provider | `$provider` |
| Snapshot time | `$taken_at` |
| Datasets | $datasets |
| Search documents | $documents |
| Archive | [`$archive`]($archive) |
| Bytes | $bytes |
| SHA-256 | `$sha256` |

`catalogue.jsonl` exposes the same typed catalogue projection used by the Hub
viewer. `viewer.json` binds it to this exact archive digest.
